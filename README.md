## :book: Sobre
O **Meu Planner** é um widget de estudos desenvolvido para ajudar a organizar atividades e manter o foco. O app conta com temas personalizáveis (Dark e Rosa Fofo), relatórios de desempenho e um sistema inteligente de "Efeito Cascata" para lidar com imprevistos.

Seja para estudar para a faculdade, cursos ou focar no trabalho, este aplicativo garante que seu tempo seja gerido de forma otimizada.

---

## :sparkles: Features
- [x] **Gestão de Atividades:** Planeje sua agenda semanal com blocos de estudo e pausas.
- [x] **Sistema de Check-in (Start):** O cronômetro só começa quando você clica em "Começar".
- [x] **Pausa Inteligente:** O tempo de pausa é somado ao final da tarefa e empurra as próximas da agenda.
- [x] **Dashboard de Desempenho:** Acompanhe suas horas líquidas de foco, tarefas concluídas e faltas.
- [x] **Temas Customizáveis:** Modo Escuro Profundo e Rosa Vibrante (Fofo).
- [x] **Widget Always-on-Top:** O app pode ser fixado sobre outras janelas.
- [x] **Perfil Personalizado:** Edite seu nome e foto de exibição.

## :rocket: Como Rodar

### Pré-requisitos
Antes de começar, você vai precisar ter instalado na sua máquina o [Node.js](https://nodejs.org/en/) e o [Git](https://git-scm.com/). Além disso, é bom ter um editor para trabalhar com o código, como o [VSCode](https://code.visualstudio.com/).

### Instalação e Execução

```bash
# Clone este repositório
$ git clone https://github.com/Lintzz/planner-app.git

# Acesse a pasta do projeto no terminal
$ cd planner-app

# Instale as dependências
$ npm install

# Execute a aplicação em modo de desenvolvimento
$ npm run start

# Para gerar o executável da aplicação
$ npm run dist
```
